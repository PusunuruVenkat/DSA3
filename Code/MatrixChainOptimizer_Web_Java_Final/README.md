# Matrix Chain Optimizer — Java Web Application

This version is designed to match the supplied dark, compact futuristic UI reference.

## Stack
- Java 17
- Spring Boot 3.5
- HTML5 / CSS3
- Vanilla JavaScript

The Matrix Chain Multiplication and Interval DP calculation runs in the Java backend.

## Features
- Matrix dimension input
- Interval DP minimum-cost calculation
- Optimal parenthesization
- Naive left-to-right comparison
- Operations saved
- Efficiency gain
- DP cost table
- Random test case
- Export report
- Print
- Responsive dark/cyan interface

## Run
Install JDK 17+ and Maven.

From the project directory:
mvn spring-boot:run

Then open:
http://localhost:8080
